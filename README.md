# SealShuffle

Rough BOM (will refine as I prototype):

2x DC motors + gearboxes ~$20
Motor driver ~$8
LiPo battery + holder ~$10-15
3D printer filament ~$15
Buttons, wires, connectors ~$10
Hardware (screws, bearings) ~$20
OLED display (optional) ~$5
Total: ~$100-105
